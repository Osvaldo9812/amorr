# Tú & yo, siempre

Una cronología romántica con fotografías mensuales, mensajes de agradecimiento, apoyo y una carta de amor interactiva.

## Desarrollo local

```bash
npm install
npm run dev
```

## Publicar en Render

El archivo `render.yaml` deja listo el servicio. En Render, selecciona **New > Blueprint**, conecta este repositorio y confirma la creación del servicio. Cada nuevo cambio en la rama principal se publicará automáticamente.

## Compilar

```bash
npm run build
```
